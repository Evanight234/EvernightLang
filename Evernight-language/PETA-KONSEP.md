## 🔬 2. Ekosistem Sains Data & Machine Learning (Matra & March)
Ekosistem komputasi ilmiah dan web notebook interaktif:
- [[MATRA]] — Pustaka all-in-one Sains Data & Machine Learning:
  - `matra.larik` (Tensor & Aljabar Linear)
  - `matra.tabel` (DataFrame & Parser CSV)
  - `matra.grafik` (Engine Plot Vektor SVG)
  - `matra.latih` & `matra.alur` (Data split, K-Fold, SMOTE, Pipeline)
  - `matra.model` & `matra.metrik` (Klasifikasi, Regresi, KMeans, Evaluasi)
  - `matra.syaraf` & `matra.pelatih` (Autograd, Deep Learning, Adam Optimizer)
- [[MARCH]] — Web Notebook interaktif berbasis format `.emlbn` (*Evernight Machine Learning Notebook*):
  - Antarmuka Google Colab Dark Mode
  - Akses dataset & berkas lokal 100% dari harddisk laptop
  - Stateful VM Kernel execution & Rich Media capture
