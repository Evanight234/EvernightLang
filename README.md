Bahasa pemrograman baru dengan sintaksis Bahasa Indonesia: *se-mudah Python, se-cepat C++, se-multifungsi JavaScript.*

```evernight
fungsi utama() {
    cetak("Halo Dunia dari EvernightLanguage!")
}
```

**Versi Aktif: v0.2.0**

- **Ekosistem**: Compiler bytecode + VM (murni Rust, zero external dependencies).
- **Pustaka Data Science & ML**: Pustaka `Matra` (`matra.larik`, `matra.tabel`, `matra.grafik`, `matra.model`, `matra.syaraf`, `matra.pelatih`).
- **Web Notebook**: **March** (`evernight march`) interaktif dengan format `.emlbn` dan antarmuka web modern Colab Dark Mode.
- **Tooling**: REPL interaktif, Language Server (`evernight-lsp`), linter, formatter, package manager, GUI installer, ekstensi VS Code.
