# EvernightLanguage

![Evernight logo](assets/logo/logo.png)

Bahasa pemrograman baru dengan sintaksis Bahasa Indonesia: *se-mudah Python, se-cepat C++, se-multifungsi JavaScript.*

```evernight
fungsi utama() {
    cetak("Halo Dunia dari EvernightLanguage!")
}
```

**Status: Fase 3 (Standard Library + Identitas Visual).** Fase 1–2 (desain bahasa, lexer/parser/compiler/VM) selesai.

> README ini sementara. Versi lengkap (quickstart, contoh program, referensi stdlib, panduan install) menyusul di Fase 5.
